## 剩余 blocker（都不是支付核心 bug，建议排期）

### B1 — session channel topUp 402（运营，影响 openai/anthropic/openrouter/dune）
admin 脚本 `open-tempo-channel.ts` 给 channel 充链上 deposit 时，topUp 走 merchant 402 过不去（`Top-up POST failed with status 402`）。结果链上 deposit 上不去，voucher amount 超过 on-chain deposit → `amount-exceeds-deposit`。
**这是 [[mpprouter_tip1034_shipped]] memory 里已记录的残留。** 修复方向：让 admin 脚本的 topUp 凭证能过 merchant 402，或换支持更高初始 deposit 的开 channel 流程。

### B2 — gemini upstream 通配符路径（配置，影响 gemini）
`gemini` 的 upstreamPath 是 `/{version}/models/*`，`resolveUpstreamPath` 不替换字面 `*`，导致转发 `/v1beta/models/*` 而非 `/v1beta/models/gemini-2.0-flash:generateContent` → merchant 404。
修复方向：让 `OPERATOR_OVERLAY` 支持覆盖 `upstreamPath`（目前不支持），给 gemini 一个显式正确路径（含 Google 的 `:generateContent` 冒号语法）。**付款层已验证 OK，只差这个路径。**

### B3 — alchemy / quicknode merchant 5xx（merchant 侧，非我们）
两者我们付款都成功，下游 merchant 返回 5xx。已在 overlay 标 verifiedMode false + note，catalog 不再对外广告其 stellar intent（避免 agent 往黑洞付钱）。等 merchant 修好后用本 suite 复测。
